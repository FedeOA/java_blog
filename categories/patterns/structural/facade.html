Patrón Facade

Patrón estructural que simplifica la interfaz a una subestructura de subsistemas.

← Volver a Patrones de diseño

¿Qué es el patrón Facade?

El patrón Facade proporciona una interfaz simplificada a un conjunto de interfaces en un subsistema complejo. Permite a los clientes utilizar el sistema sin acceder directamente a las clases individuales del subsistema, facilitando su uso y reduciendo la dependencia entre ellos.

Problema que resuelve

Ocurre cuando un cliente tiene una interacción compleja con varios componentes de un subsistema. La creación de instancias y coordinación entre estos componentes puede volverse difícil y propensa a errores.

Solución

Se crea una clase Facade que proporciona un método único de interfaz simplificada al cliente, ocultando la complejidad interna del subsistema. El Facade se encarga de coordinar las llamadas a los componentes necesarios para cumplir con la solicitud del cliente.

Estructura

  • Facade: proporciona una interfaz simplificada al subsistema.
  • Subsistema: conjunto de clases complejas con muchas funcionalidades.
  • Client: interactúa únicamente con el Facade.

Ejemplo en Java


// Subsistema
interface CuentaBancaria {
    void abrirCuenta();
}

class Ahorro implements CuentaBancaria {
    @Override
    public void abrirCuenta() {
        System.out.println("Cuenta de ahorro abierta.");
    }
}

class Corriente implements CuentaBancaria {
    @Override
    public void abrirCuenta() {
        System.out.println("Cuenta corriente abierta.");
    }
}

// Facade
class FachadaBanco {
    private Ahorro ahorro;
    private Corriente corriente;

    public FachadaBanco() {
        this.ahorro = new Ahorro();
        this.corriente = new Corriente();
    }

    public void abrirCuentaAhorro() {
        ahorro.abrirCuenta();
    }

    public void abrirCuentaCorriente() {
        corriente.abrirCuenta();
    }
}

// Client
public class Main {
    public static void main(String[] args) {
        FachadaBanco banco = new FachadaBanco();

        banco.abrirCuentaAhorro();
        banco.abrirCuentaCorriente();
    }
}

¿Cuándo usar el patrón Facade?

  • Cuando se necesita una interfaz simplificada a un subsistema complejo.
  • Para desacoplar un cliente de los detalles internos de un sistema.
  • Para proporcionar acceso limitado a las funcionalidades de un subsistema.

Ventajas y desventajas

✔ Ventajas

  • Provee una interfaz simplificada.
  • Desacopla el cliente del subsistema.

✖ Desventajas

  • Puede ocultar detalles importantes del sistema.
  • El Facade puede volverse una clase monolítica si no se implementa correctamente.
